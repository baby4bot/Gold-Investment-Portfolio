# 🥇 Gold Investment Portfolio (พอร์ตทองคำ)

แอปพลิเคชันสำหรับจัดการพอร์ตการลงทุนทองคำแบบ Real-time

## ✨ ฟีเจอร์หลัก

- 📊 **ติดตามราคาทองคำ Real-time** — ราคาทองคำแท่งและรูปพรรณจากสมาคมค้าทองคำ
- 📈 **จัดการพอร์ตการลงทุน** — เพิ่ม แก้ไข ลบ รายการลงทุนทองคำ
- 📋 **ประวัติราคาย้อนหลัง** — ดูราคาทองคำย้อนหลังพร้อมกราฟ
- 🔐 **ระบบ PIN Code** — ป้องกันการเข้าถึงด้วย PIN
- 💬 **ระบบแจ้งเตือน LINE** — แจ้งเตือนราคาทองผ่าน LINE OA
- 🌓 **Dark / Light Theme** — สลับธีมสว่าง/มืด
- 📱 **Responsive Design** — ใช้งานได้ทั้งมือถือและคอมพิวเตอร์

## 🛠️ เทคโนโลยี

- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Backend:** Firebase Realtime Database
- **Integration:** LINE Messaging API, Google Apps Script

## 🚀 วิธีใช้งาน

1. เปิดไฟล์ `index.html` บนเบราว์เซอร์
2. สมัครบัญชีใหม่หรือล็อกอินด้วย PIN Code
3. เริ่มจัดการพอร์ตทองคำของคุณ

## ⚠️ ความปลอดภัย

- รหัสผ่านถูกเข้ารหัสด้วย **SHA-256** ก่อนเก็บใน Firebase
- ไฟล์ `.env` ไม่ถูกอัปโหลดขึ้น GitHub
